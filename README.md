# Accounting Firm Website

A professional Next.js website for an accounting firm specializing in small businesses.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Features

- Home page with company overview
- Business Solutions dropdown menu with 8 service pages
- Resources page with HMRC links
- A-Z Glossary of accounting terms
- Contact form on every page
- Responsive design with Tailwind CSS

## Structure

- `/` - Home page
- `/services/*` - Individual service pages
- `/resources` - HMRC resources and links
- `/glossary` - A-Z accounting glossary
